# Python & Bash Assignment

This repository contains my work for the Python & Bash assignment completed as part of DevOps practice.

## Tasks Completed

### 1. Grade Checker
A Python program that takes a score as input and displays the corresponding grade using if-elif-else conditions.

File: `grade_checker.py`

### 2. Student Grades
A dictionary-based program that allows a new student and grade to be added, an existing student's grade to be updated, and all student grades to be displayed.

File: `student_grades.py`

### 3. Write to a File
A Python program that takes text as input and writes it to `sample.txt`.

File: `write_file.py`

### 4. Read from a File
A Python program that opens `sample.txt` in read mode and displays its contents.

File: `read_file.py`
